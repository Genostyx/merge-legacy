# Rejected Ideas

These proposals were rejected and are recorded so they are not re-proposed:

- *An "overclock" that clears a producer's cooldown for coins.* Directly attacks the project's own rule that the dispenser recharge wait IS the gate and IS the fun. `rushSource` already offers this priced in GEMS, which keeps it exceptional; paying in the abundant currency would make skipping the wait routine and the gate would effectively stop existing.
- *Coin-to-energy conversion.* Workable only under a tight daily cap, and it cannibalises `ENERGY_REFILL_COST_GEMS` - one of the few gem sinks in the build. Not worth trading a gem sink for a coin sink.
- *A bubble popper.* There is no bubble mechanic in this game.
